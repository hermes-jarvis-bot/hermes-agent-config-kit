# Каталог скиллов

Русский перевод `README.md` (103 скилла на момент последнего обновления). Это
**переводимый вручную** файл — он не генерируется скриптом, потому что перевод
требует смысловой интерпретации, а не механического преобразования. При
добавлении или существенном изменении скилла обновляй `README.md` через
`python3 scripts/generate_skills_catalog.py`, а затем синхронизируй перевод здесь.

## Установка

Этот адаптер никогда не устанавливается напрямую в живой профиль Hermes.
Сначала просмотр, потом применение — в одноразовый или реальный Hermes-home
через собственный установщик адаптера:

```bash
python3 scripts/install_hermes.py --dry-run --hermes-home /tmp/hermes-home
python3 scripts/install_hermes.py --apply --hermes-home /tmp/hermes-home
```

Это копирует все скиллы ниже в `<hermes-home>/skills/config-kit/`, сохраняя
структуру категорий, показанную здесь. Удаление — тем же способом через
`scripts/remove_hermes.py --dry-run|--apply`.
