# Каталог шаблонов

Данные-только Hermes-адаптированные шаблоны. Ни один из них не создаёт файлы, не
инициализирует состояние, не запускает агента и не активирует автоматизацию сам по себе —
каждый это стартовая точка, которую оператор копирует в одобренное проектом место и
заполняет, с подтверждением оператора перед любым write-impacting, внешним или
продакшн-действием.

Этот файл ведётся вручную (шаблонов слишком мало, чтобы генератор-скрипт оправдывал свою
сложность) — обновляй его при добавлении, удалении или выводе шаблона из эксплуатации.

## Установка

Сначала просмотр, потом применение — в одноразовый или реальный Hermes-home через
собственный установщик адаптера:

```bash
python3 scripts/install_hermes.py --dry-run --hermes-home /tmp/hermes-home
python3 scripts/install_hermes.py --apply --hermes-home /tmp/hermes-home
```

Это копирует все шаблоны ниже в `<hermes-home>/templates/config-kit/`. Удаление — тем же
способом через `scripts/remove_hermes.py --dry-run|--apply`.

## Запись агентской задачи

Набор записей на одну ограниченную, долгоживущую, многосессионную или высокорисковую
задачу. Принимать только те записи, что реально нужны проекту.

| Шаблон | Описание |
|---|---|
| [agent-task-overview.md](agent-task-overview.md) | Индекс, объясняющий что такое набор записей agent-task и когда его принимать. |
| [agent-task-spec.md](agent-task-spec.md) | Замороженная цель и критерии приёмки для одной ограниченной задачи, согласованные до начала работы. |
| [agent-task-state.md](agent-task-state.md) | Текущее машиночитаемое состояние одной ограниченной задачи. |
| [agent-task-evidence.md](agent-task-evidence.md) | Индекс одобренных проектом доказательств (вывод тестов, логи, артефакты) для ограниченной задачи. |
| [agent-task-trace.md](agent-task-trace.md) | Одно рассмотренное событие в таймлайне ограниченной задачи. |
| [agent-task-verdict.md](agent-task-verdict.md) | Независимая запись вердикта PASS/FAIL/BLOCKED для ограниченной задачи. |
| [agent-task-fix-log.md](agent-task-fix-log.md) | Журнал проходов исправлений по находкам вердикта. |
| [agent-task-problems.md](agent-task-problems.md) | Находки верификатора для устранения, пишется когда вердикт FAIL или HOLD. |
| [agent-task-handoff.md](agent-task-handoff.md) | Структурированный хендофф по одной ограниченной задаче между сессиями. |
| [agent-task-scratchpad.md](agent-task-scratchpad.md) | Короткоживущая рабочая память для возобновления задачи — не транскрипт. |
